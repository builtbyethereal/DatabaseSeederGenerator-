# Database Seeder Generator

A private, browser-based database seeder generator for creating realistic sample data for development and testing.

## Features

- Generate seed data directly in the browser
- Output formats: SQL INSERT, JSON, CSV, JavaScript array, and Laravel seeder code
- SQL dialect support for MySQL, PostgreSQL, SQLite, and generic SQL
- Built-in templates for users, products, orders, employees, and API test data
- Configurable fields, data types, nullable values, unique values, and type-specific options
- Optional random seed for repeatable generated data
- Preview table, output statistics, copy, download, select-all, and regenerate controls
- Light and dark theme support

## Run Locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deployment

This project is ready for static hosting on GitHub Pages or any static web host.

## Privacy

All seed data is generated locally in the user's browser. The app does not upload, store, or send generated content anywhere.
